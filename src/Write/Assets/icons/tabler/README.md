# Tabler Icons (vendored)

- Source: https://github.com/tabler/tabler-icons
- Version: **3.45.0**
- License: MIT (see upstream `LICENSE`)

These SVGs are a curated subset of Tabler Icons 3.45.0 used by the BeexWrite
shell (menus, sidebar, toolbar, status bar). They are committed into the
repository so the build never depends on any external icon folder.

Each icon is a 24x24, 2px-stroke outline glyph. `currentColor` is used for the
stroke so WPF/CSS can recolour them per theme. To add more icons, copy the
matching `*.svg` from the Tabler Icons 3.45.0 release into this folder.
